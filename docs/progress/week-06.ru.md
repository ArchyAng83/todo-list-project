# Неделя 6 — календарь на месяц

Даты: 2026-12-07 — 2026-12-13

Статус: код готов; все наборы тестов зелёные

## Цели

- Месячный календарь по `/calendar`, который ставит задачи на их срок.
- Переключение между месяцами, возврат к сегодняшнему дню и сохранённое начало недели пользователя.
- Создание задачи по клику на день с подставленной датой.
- Integration-, component- и E2E-покрытие размещения, создания и навигации.

## Сделано

- `CreateTaskRequest` и `CreateTaskBody` получили необязательные `Priority`, `DueDate` и `DueTime`, добавленные в конец, поэтому существующие вызовы продолжают компилироваться.
- `CreateTaskRequestValidator` отклоняет неизвестный приоритет и время без даты.
- `TaskService.CreateAsync` применяет приоритет и срок через существующие методы агрегата.
- `TaskQueries.CalendarAsync` возвращает задачи, чей `DueDate` попадает во включительный диапазон, с сортировкой по дню, времени, статусу и приоритету.
- `ListAsync`, `BoardAsync` и `CalendarAsync` используют одно выражение проекции `ToListItem`, поэтому список, доска, календарь и API не расходятся.
- `GET /api/v1/tasks/calendar?from=&to=` отдаёт диапазон API-клиентам и отвечает `400`, если `from` позже `to`.
- Страница `/calendar` с состояниями загрузки, ошибки и повтора, переключением месяцев, кнопкой «Сегодня» и ссылкой на список задач.
- Страница читает `UserSettings.WeekStart` и запрашивает ровно видимое окно в 42 дня, включая соседние дни, которыми заполняется сетка.
- Презентационный компонент `CalendarGrid`: заголовки дней недели с учётом культуры, стиль дней другого месяца, отметка сегодняшнего дня и сетка из 42 ячеек, рассчитанная от настроенного начала недели.
- До трёх чипов задач в дне, отсортированных запросом, со счётчиком «и ещё N» и полным названием в подсказке.
- Выполненные задачи зачёркнуты, а незавершённые задачи до сегодняшнего дня получают акцент просрочки.
- Ячейки дней доступны с клавиатуры: `Enter` и `Space` открывают диалог создания, а чипы задач останавливают всплытие, поэтому редактирование задачи никогда не создаёт новую.
- `TaskCreateDialog` с подставленной датой клика, а также проектом, приоритетом, сроком и временем.
- Пункт навигации, ключи ресурсов `Calendar`/`CalendarTitle`/`CalendarHint`/`NewTask`/`Today`/`PreviousMonth`/`NextMonth`/`MoreTasks` на английском и русском.
- Стили сетки календаря и чипов в `app.css`, включая компактную раскладку ниже 700px.
- 1 integration-тест на фильтрацию диапазона, сортировку, изоляцию пользователей и перевёрнутый диапазон; 2 API-теста для endpoint-а календаря.
- 9 bUnit-тестов: загрузка, ошибка/повтор, начало недели с понедельника и с воскресенья, размещение и стили задач, счётчик переполнения, клик по дню, клик по задаче и управление месяцем.
- 3 E2E-сценария Playwright: демо-задачи на своих датах, переключение месяцев и создание по клику с проверкой после перезагрузки.

## Решения

- `CalendarAsync` возвращает `TaskListItem`, поэтому календарь, список, доска и `/api/v1` сохраняют одну форму задачи, а API остаётся аддитивным.
- Сервер отдаёт плоский упорядоченный список для диапазона; сеткой из 42 дней владеет UI, потому что она зависит от сохранённого начала недели, а не от данных задач.
- Страница запрашивает всё окно сетки, а не только текущий месяц, чтобы задачи в начальных и конечных днях не терялись.
- `CreateTaskRequest` получает необязательные параметры в конце вместо нового типа запроса; все существующие вызовы и API-клиенты остаются валидными.
- Ячейка дня — цель для создания, а чип задачи — цель для редактирования. `@onclick:stopPropagation` на чипе делает эти действия однозначными.
- Сетка показывает по три чипа в дне и сворачивает остальные в счётчик: ячейка месяца слишком мала для удобной прокрутки, а подсказка сохраняет доступ к полному названию.
- Названия месяцев и дней недели берутся из `CultureInfo.CurrentCulture`; CSS капитализирует заголовок месяца, поэтому русские названия со строчной буквы всё равно читаются как заголовок.

## Исправлено после E2E

- `ComponentTestContext` задавал только `CurrentUICulture`, а календарь форматирует месяцы и дни недели из `CurrentCulture`. На русской машине bUnit-проверки сравнивали английские ожидания с русским выводом. Теперь контекст фиксирует обе культуры на `en`.
- E2E-тест создания в календаре кликает по номеру дня, а не по центру ячейки: центр может попасть на существующий чип задачи и открыть редактирование вместо создания.
