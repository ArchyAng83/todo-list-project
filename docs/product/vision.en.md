# Vision

## Problem

Tasks live across notes, chats, calendars, and memory. A good task manager should make it obvious what to do next, keep deadlines and reminders reliable, and stay out of the way.

## Product

TodoList is a focused task manager with projects, tags, subtasks, priorities, due dates, email reminders, recurring tasks, Kanban, calendar, and import/export. The core is a real multi-user product, not a CRUD demo.

## Audience

- Primary: the author, as a production-quality portfolio project.
- Secondary: reviewers evaluating .NET full-stack and AI engineering skills.

## Demo scenario

1. Register or sign in.
2. Create a project, tags, and several tasks.
3. Plan Today and Upcoming, then complete a recurring task.
4. Receive an email reminder and inspect it in Mailpit.
5. Switch RU/EN and light/dark.
6. Explore the REST API via OpenAPI/Scalar.

## Success criteria

- A live URL with a seeded demo account.
- Production-quality auth, data isolation, tests, CI, and deployment.
- Clean seams for the future AI layer: Application services, API, telemetry, and evals.
