# Неделя 3 — UX и REST API

Даты: 2026-11-16 — 2026-11-22

Статус: код готов; проверки API и страниц пройдены

## Цели

- Представления и сортировка задач поверх поиска и фильтров.
- Сохраняемые настройки пользователя: язык, тема, часовой пояс, начало недели, напоминание по умолчанию.
- Детерминированный демо-аккаунт с показательными данными.
- Минимальный REST API `/api/v1` с bearer-токенами, OpenAPI и Scalar.
- Integration-покрытие аутентификации API, изоляции данных, представлений, сортировки и настроек.

## Сделано

- `TaskView` (All, Inbox, Today, Upcoming, Completed) и `TaskSort` (Default, DueDate, Priority, Created, Title).
- `TaskQueries` применяет представления и сортировку в SQL, а «сегодня» вычисляет в часовом поясе пользователя из `UserContext`.
- На странице задач появились кнопки представлений, выбор сортировки и подсветка просрочки с учётом часового пояса.
- Слой настроек: `UserSettings`, `UpdateUserSettingsRequest`, правила FluentValidation, `IUserSettingsStore` и `UserSettingsService`.
- `UserSettingsStore` сохраняет настройки через Identity в Infrastructure, не протаскивая Identity в Application.
- Страница настроек редактирует имя, язык, тему, часовой пояс (с поиском), начало недели и напоминание по умолчанию; есть состояния загрузки, ошибки и валидации.
- `ThemePreference` синхронизирует тему MudBlazor; layout следует системной теме через небольшой помощник `theme.js`.
- `DemoDataSeeder` создаёт `demo@todolist.local` с тремя проектами, тремя тегами, восемью задачами и чек-листами; управляется `Seed:Demo`.
- Собственный endpoint входа `POST /api/v1/auth/login`, выдающий access- и refresh-токены.
- Группа `/api/v1` только для bearer-токенов: задачи, проекты, теги и `/me/settings`.
- OpenAPI-документ по `/openapi/v1.json` и Scalar UI по `/scalar`.
- Строковые enum в JSON; `DateOnly`/`TimeOnly` используют стандартное ISO-представление.
- Integration-тесты: вход по bearer, отказ cookie-аутентификации, изоляция задач, представления, сортировка по приоритету, сохранение настроек и валидация часового пояса.
- Английские и русские ресурсы для всех новых строк.

## Решения

- Собственный endpoint входа вместо `MapIdentityApi`, чтобы контролировать форму ответа, коды состояния и метаданные OpenAPI.
- Группа API явно требует `IdentityConstants.BearerScheme`; cookie, используемая Blazor, не даёт доступа к `/api/v1`.
- `IUserSettingsStore` принадлежит Application, а Infrastructure реализует его через `UserManager`. Типы ASP.NET Core Identity не попадают в Application.
- `TaskListFilter` расширен только добавлением `View` и `Sort`, поэтому позиционные вызовы в тестах не меняются.
- Сортировка по приоритету использует встроенное условие, чтобы EF Core перевёл его в `CASE`; вызов вспомогательного метода не транслируется.
- Список часовых поясов и определение системной тёмной темы остаются на краю UI; Application получает простые значения.

## Метрики

- Build: проходит с 0 предупреждений и 0 ошибок в Debug и Release.
- Тесты: 35 unit-тестов и 22 integration-теста проходят.
