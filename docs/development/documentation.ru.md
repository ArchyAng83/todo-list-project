# Политика документации

## Язык

Документация двуязычная. **Английский — основной**; русский — синхронизированный перевод.

- Файлы-пары лежат рядом: `overview.en.md` и `overview.ru.md`.
- Каждый документ начинается с переключателя: `English | Русский`.
- Английские docs обновляются первыми, в том же pull request, что и изменение.
- Русские переводы обновляются в том же PR для значимых изменений; мелкие правки можно синхронизировать на weekly review.
- Если перевод отстал, в начале русского файла ставится `> Translation status: outdated`, после перевода дата синхронизации обновляется.
- Код, идентификаторы, XML docs, commit messages и `CHANGELOG.md` — на английском.
- UI-строки локализуются через `.resx` ресурсы для RU и EN.

## Структура

```text
docs/
├─ README.{en,ru}.md
├─ product/
├─ architecture/
│  ├─ overview.{en,ru}.md
│  ├─ data-model.{en,ru}.md
│  └─ decisions/0001-...{en,ru}.md
├─ development/
├─ operations/
├─ api/
├─ progress/
│  ├─ status.{en,ru}.md
│  └─ week-XX.{en,ru}.md
└─ demo.{en,ru}.md
```

Папки и документы добавляются при старте соответствующей фазы; пустых файлов-заглушек избегаем.

## Шаблон ADR

```markdown
# ADR-XXXX: Title

- **Status:** Proposed | Accepted | Superseded
- **Date:** YYYY-MM-DD

## Context

## Decision

## Consequences
```

## Отслеживание прогресса

- `status` — текущий срез: фаза, сделано, в работе, далее, блокеры, quality gates.
- `week-XX` — итоги недели: цели, результат, решения, метрики, переносы.
- Обновлять в конце каждой рабочей сессии и в конце недели.
- User-visible изменения и релизы фиксируются в `CHANGELOG.md`.

## Чеклист ревью

- Английский и русский файлы существуют парой.
- Переключатель языка ведёт на правильный файл.
- Ссылки резолвятся.
- Документ соответствует текущему коду и статусу.
