- **В целом:** фундамент, работа с задачами, настройки, демо-данные, bearer API, компонентные тесты, E2E, контейнерный образ, Kanban-доска и календарь на месяц готовы; MVP в работе.

## Сделано

- Согласованы архитектура, scope и 8-недельный roadmap.
- Решение с Domain, Application, Infrastructure, Web и пятью тестовыми проектами.
- Central package management, зафиксированный .NET SDK, editor config, Git attributes.
- Docker Compose для PostgreSQL и Mailpit.
- CI-скелет GitHub Actions.
- Двуязычная документация и отслеживание прогресса.
- Первый коммит в ветке `main`.
- Доменная модель: проекты, теги, задачи, чек-листы, связи задач с тегами, напоминания.
- Персистентность на EF Core 10 + Npgsql, snake_case, применена первая миграция.
- ASP.NET Core Identity с cookie-аутентификацией и переименованными таблицами Identity.
- Static SSR страницы входа, регистрации, выхода и отказа в доступе.
- Оболочка на MudBlazor, публичный лендинг, страница профиля.
- Локализация RU/EN через cookie и `Accept-Language`.
- Проекты: создание, редактирование, архивация/восстановление, удаление, счётчики открытых и всех задач.
- Теги: создание, редактирование, удаление, счётчик использования, предпросмотр цвета.
- Задачи: быстрый ввод, диалог редактирования со статусом, приоритетом, проектом, сроком/временем, напоминанием, тегами и чек-листом.
- Список задач: поиск с задержкой, фильтры по статусу, проекту и тегу, переключение статуса, удаление.
- Представления задач: Inbox, Today, Upcoming, All и Completed, а также сортировка по сроку, приоритету, дате создания и названию.
- «Сегодня» и подсветка просрочки с учётом часового пояса пользователя.
- Страница настроек сохраняется через `IUserSettingsStore`: имя, язык, тема, часовой пояс, начало недели и напоминание по умолчанию.
- Живое переключение темы с определением системной темы и небольшим помощником `theme.js`.
- Детерминированный демо-аккаунт (`demo@todolist.local` / `DemoPass123`) с проектами, тегами, задачами и чек-листами, управляется `Seed:Demo`.
- Минимальный REST API `/api/v1` только с bearer-аутентификацией, собственным endpoint входа и endpoint-ами задач, проектов, тегов и настроек.
- OpenAPI-документ по `/openapi/v1.json` и Scalar UI по `/scalar`.
- Сервисы Application с разделением команд и запросов, FluentValidation и `Result<T>`.
- Unit-тесты доменных правил и настроек пользователя (35 проходят).
- Integration-тесты на Testcontainers для аутентификации, персистентности, работы с задачами, порядка на доске, диапазонов календаря и REST API (33 проходят).
- Компонентные bUnit-тесты списка задач, Kanban-доски, сетки календаря, layout и переключателя языка (31 проходят).
- E2E-сценарии Playwright против реального процесса Kestrel, PostgreSQL в Testcontainers и headless Chromium (11 проходят).
- Endpoint-ы `/health/live` и `/health/ready` с проверкой доступности базы данных.
- JSON-логирование в консоль вне Development для контейнерных платформ.
- Многоступенчатый `Dockerfile` с запуском от непривилегированного пользователя на порту 8080 и `.dockerignore`.
- CI, который запускает все тестовые наборы, ставит браузеры Playwright и собирает контейнерный образ.
- Kanban-доска по `/board` с колонками `Todo`, `InProgress` и `Done`, упорядоченными ручным порядком сортировки.
- Drag-and-drop между колонками и внутри колонки плюс меню карточки: выше, ниже и перемещение в другую колонку.
- `TaskService.MoveAsync` перенумеровывает только исходную и целевую колонки одним `SaveChangesAsync`; `TaskQueries.BoardAsync` отдаёт упорядоченную доску.
- Календарь по `/calendar` с сеткой месяца из 42 дней, задачами на их сроке, стилями выполненных и просроченных задач и переключением месяцев.
- Сетка следует сохранённой настройке `WeekStart` и показывает соседние дни, которые дополняют недели.
- Создание по клику: выбор дня открывает диалог с подставленной датой, а редактирование задачи никогда не создаёт новую.
- `TaskQueries.CalendarAsync` возвращает включительный диапазон сроков в порядке дня, времени и приоритета, а `GET /api/v1/tasks/calendar` открывает его API-клиентам.
