# Roadmap

## Timeline

| Week | Focus | Deliverable | Status |
|---|---|---|---|
| 0 | Bootstrap | Solution, docs, tests, Docker Compose, CI skeleton | ✅ |
| 1 | Foundation | EF Core, Identity, auth pages, app shell, i18n foundation | ✅ |
| 2 | Core domain | Projects, tags, tasks, subtasks, views, quick add | ✅ |
| 3 | UX + API | Search, filters, settings, demo seed, `/api/v1`, OpenAPI | ✅ |
| 4 | MVP release | bUnit, Playwright, Dockerfile, health checks, CI image build | ✅ |
| 5 | Kanban | Status columns, drag-and-drop, ordering, tests | ✅ |
| 6 | Calendar | Month view, due-date placement, create-on-click | ⬜ |
| 7 | Productivity | Recurring tasks, email reminders, dispatcher | ⬜ |
| 8 | Release v1.0 | Import/export, full E2E, accessibility, final deploy | ⬜ |

## Milestones

- **v0.1 - Bootstrap**: repository and documentation foundation.
- **v0.2 - MVP**: authenticated task manager with API and live deployment.
- **v0.3 - Views**: Kanban and calendar.
- **v0.4 - Productivity**: recurring tasks, reminders, import/export.
- **v1.0 - Release**: polished, documented, tested, deployed.

## AI phase

The AI layer starts after v1.0: natural-language quick add, tool-calling assistant, evals, tracing, and guardrails.
